Sauvegarde JSON

Sauvegarde complète NutriApp. Exporte ou réimporte les ingrédients, recettes et menus dans un JSON local. Cette base technique servira ensuite au partage plus convivial des cartes.
Exporter
Template = exemple de structure au format actuel. Export = JSON réel depuis le stockage local. Télécharger crée un fichier de sauvegarde réutilisable.
Importer
Colle un JSON complet NutriApp ou charge un fichier de sauvegarde. Valide avant d’appliquer si tu veux contrôler le contenu.
Mode d’import
Remplacer = écrase la bibliothèque.
Fusionner = ajoute / met à jour selon la règle “nom unique” (Politique A).
